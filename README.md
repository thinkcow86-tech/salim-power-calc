# ⚡ 가전 소비전력·전기요금 & 멀티탭 용량 안전 계산기

가전별 소비전력으로 한 달 전기 사용량과 **주택용 누진제 청구액**(이번 달 청구액이 얼마나 늘어나는지)을 계산하고,
같은 멀티탭에 꽂았을 때 **전류·용량이 안전한지**를 진단하는 무료 정적 웹 도구입니다.

- 요금 기준: 2026년 4분기 한국전력 주택용 요금표 (2026-11-20 확인)
- 외부 라이브러리·폰트·이미지 요청 없음 (완전 정적, 오프라인에서도 동작)
- 모바일 우선(390px) → 320px·768px·1280px 대응

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 스타일 (외부 폰트 없음) |
| `tariff.js` | 요금 계산 코어 (브라우저 `window.Tariff` / Node `require` 지원) |
| `app.js` | 화면 조작·상태 관리 |
| `embed.html` | 위 4개를 하나로 합친 단일 파일 (파일 하나로 배포·삽입할 때) |
| `embed_blogger.html` | Blogger 페이지 HTML 편집기에 붙여넣는 조각 (CSS 를 `#pcc-app` 범위로 한정해 테마와 충돌 방지) |

## 주요 기능

1. **가전 프리셋 16종 + 직접 입력** — 세탁기·건조기·에어프라이어·전자레인지·인덕션·전기포트·전기히터·전기장판·제습기·냉장고·TV·컴퓨터·공기청정기·선풍기·헤어드라이어·로봇청소기
2. **누진제 청구액** — 주거 형태(저압/고압)·계절(기타·하계·동계)·현재 월 사용량을 넣으면 가전 추가 시의 월 추가 요금·총 청구액·누진 단계 상승 여부를 계산
3. **멀티탭 안전 진단** — 같은 멀티탭에 체크한 가전의 정격 소비전력 합계와 220V 전류(A)로 일반 멀티탭(2,800W·12.7A)·고용량(4,000W·16A)·15A 차단기(약 3,300W) 기준 안전/주의/위험 판정

전기요금·안전 기준은 참고용입니다. 실제 청구액은 검침일, 복지할인, TV수신료, 계약종별에 따라 달라질 수 있습니다.
